两层华栱附近另有独立网格86、81。本记录分别显示主栱身与这些邻接网格；邻接不证明同根木料，也不证明历史分件。圈中凸块是否属于华栱本体尚未核定，不能将它并入华栱后称为资料已证明的形态。

保存七张形态卡、总览、来源位置图、邻接网格图、所选原网格坐标与来源对应表。形态参考不等于完整后端个体外形或尺寸已核定。此次记录不进行组合建模，也不改变来源网格形状。
