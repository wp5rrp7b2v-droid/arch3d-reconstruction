## 图像是什么

7张主图由`tools/forms_v002.py`绘制，包含单体轴测、侧面和端部／承托示意。全部完整轮廓均是工程候选；不是照片、测绘正投影或已经批准的模型。坐标为任意绘图单位，未从照片反算长度。虚线提示未知接口或候选区域；实线仅表示候选图的可见棱，不表示每一点均为实测事实。

1. A1：刘畅、廖慧农、李树盛《山西平遥镇国寺万佛殿与天王殿精细测绘报告》。本项目434页PDF，SHA-256：`94c2fedef64fd81ce225e04da4757d33ada34b9413b01baaf023fa72baed3472`。本轮采用PDF60、81—83、87、90、106，原页图随本目录保存。图2-70／71是报告结构解释示意，不能冒作独立单件测绘。A2、A3已登记结论继续沿用，未被包装为独立复测。
2. 官方万佛殿专题：[山西文物数字博物馆](https://szbwgvue.chwhyun.cn/wanfodian/)。既有登记文字分别明确四椽栿上及平梁上的驼峰角色。本轮未获得新单件测量，匿名数字节点身份推断边界继续保留。
3. 张荣：《中国五台山佛光寺东大殿建筑数字化勘察数据分析与唐代材分°营造法式研究》，报告末页日期2022-03-19。[原报告40页](https://www.kaah.or.kr/download/mailing/kaah_seminar_presentation1_1.pdf)。PDF16说明明栿与草栿加工差别；PDF17图示标名令栱。建筑857年。采用类型比较，不移植全套尺寸或装饰；文件旧前缀FG2021不代表实际报告年代。
4. 梁思成：《蓟县独乐寺观音阁山门考》，《中国营造学社汇刊》1932年3卷2期。[原扫描整期](https://upload.wikimedia.org/wikipedia/commons/3/3a/NLC404-01J000317-23024_中國營造學社彙刊_1932年3卷2期.pdf)。本轮读山门部分：PDF49铺作、PDF54—55梁枋及卷杀描述、PDF55—56平梁与脊部。山门984年；没有把观音阁构件或后期修补一律标成984年原件。

## 可复用与必须独立的部分

- 梁栿可共用长梁／短梁的表达方法，端部加工是局部变化；不能把所有梁统一成华丽月梁，也不能只因端部未知便永远保留直棱包络。
- 下六椽栿、上六椽栿的截面、层位及曲面不同，分别出图。表2-38的“厚”是截面进深方向，不能当侧面高度拉伸。
- 山面平梁只复用朴素短梁类型；346mm材广、未知厚度、实际跨度和接口独立。245.4mm参数补全不升级为实测。
- 令栱可共享横栱卷杀类型；内外位置、顶面交接、瓣数与尺寸须逐类核对。
- 两种驼峰只共享展开承托概念。下层承斗栱、脊部承蜀柱，不能因同名直接复制实体。

## 这一阶段证明了什么

证明了多数目标页可以用明确标识的、可回查来源的类型候选图替代难辨组合裁切，从而进入PO外形方向审核。没有证明所有候选是963年万佛殿原貌，也没有证明F008的完整单体。静态／Chrome检查仅证明显示、交互、来源链与保护范围；逐页证据结论另列。
