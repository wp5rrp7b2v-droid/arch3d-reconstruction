  • 佛光寺857年：采用明／草栿区分和简单批竹式昂的类型比较；不移植其栌斗泥道截直特例。

  • 华林寺964年、保国寺1013年：地域与构架不同，用于检验“早期都应同形”的假设；未用其特殊月梁／云形做法补本殿缺口。保国寺图源已在A1图2-29复核，未重复收集。
  • 本殿下六椽栿、上六椽栿、四椽栿：优先保留原照片能看出的差别，未将所有梁画成同一种月梁。
  • 山面平梁与两种驼峰：V001完整可信单体不足；V002另给有边界的类型候选，仍未证明本殿完整单件。
