## PASS／FAIL先验标准

视觉PASS：实际Chrome中能看到独立候选单体、侧面及端部／承托特征；图像可放大；文字无遮挡或裁切，图C身份明确；未配准、非实测的限制可见。若图片缺失、主图仍只是难辨组合剖面、关键特征不可辨或候选被误标为实测，则FAIL。

基本形制证据PASS：本殿资料或可靠时代类比足以支持本页提出的基本类型；每条具体建议能回查实际采用来源；未验证细节显式保留。F007允许“朴素短梁候选”级通过，不等于本殿山面完整单体已证明。若仅有名称／作用、不能支持同作用单体轮廓，则证据FAIL，不因图画得清楚而通过。

工程保护PASS：其余9页及其数据保持；16页原模型渲染身份、局部批准范围、位置和数量语义保持；没有修改正式Master、BLEND、Registry、Dashboard、Project Control、PR72或PR73，不合并main。

逐页总体PASS须视觉与限定用途的证据均PASS。F008即使浏览PASS，也因单体形制证据未闭合保留总体FAIL。所有PASS仍不是PO批准、历史精确几何证明或正式生产准备通过。
