## 3. 直接原页未取得时的证据纪律

从本批次开始，所有参数字段统一使用以下直接核读状态：

- `DIRECT_VERIFIED`：已直接看到主报告原页/原图并核对；
- `A_BRIDGE_VERIFIED`：正式论文明确转引主报告数据或页码，但主报告原页未直接看到；
- `REPORT_INFERRED`：主报告或后续论文的设计推定；
- `SECONDARY_SUPPORT`：机构展示/二手资料；
- `HYPOTHESIS`：后续研究提出的尺度解释；
- `UNKNOWN`：没有足够证据。
