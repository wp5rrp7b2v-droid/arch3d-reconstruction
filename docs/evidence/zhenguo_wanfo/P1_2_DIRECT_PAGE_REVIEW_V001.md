## 10. 直接核读发现的两项页码纠错

### CORR-001｜“第147页=檐部三段尺度”错误

直接打开主报告 PDF p162 / 印刷 p147 后确认：该页属于第四节“彩画作”，内容为彩画叠压痕迹显微表，**不是檐出/铺作尺度页**。

因此 Batch 04 / Batch 05 中“回主报告第147页核对2677.5/1224/1453.5mm”的表述应视为错误页码归属。

正确处理：

- 2677.5 / 1224 / 1453.5mm 暂继续保留为外部正式论文/2012《大木结构测量数据解读》的 `A_BRIDGE_VERIFIED` 数据；
- **不得升级为主报告 DIRECT_VERIFIED**，除非在主报告其他实际页面找到相同定义或直接取得2012论文原页。

### CORR-002｜“第107页=小斗同规格设计”页码归属错误

直接打开主报告 PDF p122 / 印刷 p107 后确认：该页属于2.6.2.2“斗栱层”理想模型与现状叠合图，**不是散斗/齐心斗/交互斗同规格论证页**。

因此“主报告第107页直接支持小斗同规格”这一页码归属撤销。

该观点如继续使用，只能保留为后续正式论文的 `REPORT_INFERRED / A_BRIDGE`，不能称为“主报告第107页直接核读”。
