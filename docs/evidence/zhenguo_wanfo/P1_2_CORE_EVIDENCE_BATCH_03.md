## 0. 本批次方法

Batch 03 不再追求“更多一般介绍”，而是回答三个几何问题：

1. 屋顶从撩檐槫到脊槫的几何关系是否已经足够形成剖面；
2. 柱高—铺作层—檐高—屋脊总高是否已经足够形成可靠Z轴控制；
3. 转角铺作、角华栱、角梁、丁栿的拓扑是否已经足够形成角部3D骨架。

本文件继续使用以下标签：

- **A / A-Bridge**：核心专业来源，或可明确追溯到《精细测绘报告》的正式论文数据；
- **B**：机构/专业数字展示，可作为强佐证和结构拓扑证据；
- **C**：媒体、考察报告、专业科普等二手材料，只作交叉验证；
- **HYPOTHESIS**：论文/预印本作者的尺度解释、模数化或复原假说，不作为直接实测值。

## 1. 屋架与举折

### E-027｜主体梁架拓扑进一步确认｜B

镇国寺万佛殿数字展示对主体梁架给出较完整的拓扑描述：

- 梁架彻上露明，为复合式六椽栿通檐用两柱；
- 下六椽栿置于二跳华栱之上；
- 上六椽栿置于铺作之上，上出令栱承襻间枋；
- 四椽栿两端设托脚；
- 四椽栿上以驼峰、令栱承平梁；
- 平梁、四椽栿、六椽栿之间以隔架铺作承托；
- 平梁上再设驼峰、蜀柱、叉手承脊槫。

**当前判断：主体梁架的“连接顺序/构件层级”已经较清楚，可进入后续拓扑骨架设计；但各构件中心线坐标、截面尺寸与Z向标高仍不能锁定。**

### E-028｜数字展示的屋面举折数值｜B / 测量口径待核

镇国寺万佛殿数字展示给出：

- “撩檐槫至脊槫”为 **13.62 m**；
- “举高”为 **3.51 m**；
- “大殿举折”为 **1:3.88**。

13.62 / 3.51 ≈ 3.88，与页面所列比值一致。

但“撩檐槫至脊槫13.62m”的具体几何定义仍不清楚：从数量级看更接近整个屋顶方向的总控制尺度，而不像单坡水平架道；在未直接看到《精细测绘报告》剖面/测点定义前，**不能把13.62m直接当作单侧水平run或斜长写入3D参数。**

### E-029｜二手垂直/檐出数据与E-028存在90mm级差异｜C

多份二手资料重复给出：

- 檐高约 **5.27 m**；
- 檐出约 **2.94 m**；
- 举高约 **3.60 m**；
- 总高约 **8.87 m**。

其中 5.27 + 3.60 = 8.87，说明这组数据内部使用的是3.60m屋面高度口径。

但数字展示给出的举高为3.51m，两者相差 **90 mm**。目前不能判断属于：

- 不同测绘时期；
- 不同起止点；
- 科普取整；
- 历史引用口径差异。

因此这组值只能作为**C级垂直校核范围**，不能锁参数。

### E-030｜2025预印本的“屋举138小寸”只能作为模数假说｜HYPOTHESIS

2025年预印本《中国古代建筑模数-平遥镇国寺万佛殿》提出：

- 营造尺 = 307.476 mm；
- 每尺12“小寸”；
- 屋举 = 138小寸；
- 折屋按衰分计算。

按该文自己的尺制换算，138小寸约为 **3535.974 mm**，与数字展示3.51m接近。

但该文属于预印本，且其尺制推定与Batch 02中肖旻2024文采用/转引的约305.7–306mm体系并不完全相同。因此：

**此结果只说明“3.5m级屋举”具有多来源一致性，不足以证明3535.974mm就是五代原设计值。**

## 2. 柱网垂直控制

### E-031｜侧脚、生起存在可以确认；精确生起量仍未达到A层｜B + C

数字展示明确确认：

- 柱有侧脚；
- 角柱有生起；
- 生起会通过生头木继续影响脊槫和其他各槫，使屋面形成曲面。

但该数字展示未给出万佛殿自身的具体生起量。

多份二手资料给出：

- 檐柱高约 **3.42 m**；
- 柱径约 **0.46 m**；
- 角柱生起约 **0.05 m**。

其中3.42m柱高已经在Batch 02被判定为高风险：原始地坪/柱础标高不明，不能直接视为963年设计柱高。0.05m生起也尚未由《精细测绘报告》2.1.3“角柱生起”原页直接复核。

**当前状态：侧脚/生起作为几何机制可锁；具体侧脚量与50mm生起暂不锁。**

### E-032｜现有Z向数字之间不能直接拼成一个“正确立面”｜C / 定义冲突

二手资料常见：柱高约3.42m、斗栱层总高约1.74m、檐高约5.27m。

简单相加 3.42 + 1.74 = 5.16m，与5.27m相差约110mm。该差异说明“柱高”“铺作总高”“檐高”的测量起止面并不一定一致，或者来源并非同一套测绘数据。

同理：

- 5.27 + 3.60 = 8.87m；
- 若采用数字展示3.51m举高，则为8.78m。

因此当前**禁止**把这些二手标量直接拼装成Blender Z轴。

## 3. 转角铺作与角梁

### E-033｜转角铺作拓扑已达到较强结构证据｜B

镇国寺万佛殿数字展示明确描述：

- 四个角柱各置一朵转角铺作，共4朵，结构相同；
- 正身转角斗栱为七铺作、双杪双下昂，与柱头铺作基本体系相同；
- 45°方向出两跳角华栱，托双昂，再上出由昂；
- 瓜子栱“鸳鸯交手”；
- 最上令栱承短替木，托撩檐槫；
- 里转出三跳，第三跳承托角梁。

这已经足够定义**角部构件拓扑图（graph / connection topology）**，但仍不足以定义各斜向构件的精确长度、标高、斜率及榫卯落位。

### E-034｜柱头铺作在前后檐与山面的后尾承担不同构件｜B

同一数字展示进一步说明：

- 前后檐柱头铺作尾部承六椽栿；
- 两山柱头铺作尾部承丁栿。

这意味着未来3D参数结构不能把四面柱头铺作简单实例化为“完全同功能”；外形体系虽相同，**后尾连接目标不同**，应在数据模型中区分 `front_rear_eave` 与 `gable_side` 两类连接语义。

### E-035｜角梁后尾证据出现文献冲突｜B vs C/B-Secondary

数字展示称：

- 老角梁后尾设“隐衬角栿”；
- 老角梁后尾“扣合槫”；
- 并称这些做法属于现存较早实例。

但另一篇讨论唐宋歇山角梁制度的文章在列举实例时，把镇国寺万佛殿归入“只用大角梁而不设隐角梁”的案例。

目前不能确定这里是：

1. “隐衬角栿”与“隐角梁”术语所指不同；
2. 两文作者对同一构件有不同判断；
3. 修缮后状态或图纸判读差异。

**处理规则：角梁后尾是否存在独立隐角梁/隐衬角栿，正式模型暂不锁定，必须回《精细测绘报告》角部图版解决。**

- 45°斜向构件精确尺寸；

## 8. 当前判断

Batch 03 后，万佛殿已经具备：

- 较可靠的平面精测候选；
