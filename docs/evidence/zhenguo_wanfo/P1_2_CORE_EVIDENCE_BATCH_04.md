## 2. 檐出控制｜第一次拿到带主报告页码的正式表格数据

### E-032｜《镇国寺报告》第147页派生的檐部三段水平尺度｜A-BRIDGE

《建筑史学刊》2024年第1期《晋阳古城二号建筑基址一号殿复原研究》表6，明确引用：

> 镇国寺万佛殿 [《平遥镇国寺万佛殿大木结构测量数据解读》/主报告体系，第147页]

并列出：

- 椽头至檐柱柱心平出距离：**2677.5 mm**
- 文中定义的“檐出”（椽头至橑檐枋的平出距离）：**1224 mm**
- 铺作外跳长：**1453.5 mm**
- 1224 / 2677.5 ≈ **0.46**

三者关系满足：

`1224 + 1453.5 = 2677.5 mm`

### 重要修正

此前二手资料常见“檐出约2.94m”。Batch 04 说明：

- “檐出”存在不同起止点定义；
- 2677.5mm 是椽头到檐柱柱心；
- 1224mm 是椽头到橑檐枋；
- 1453.5mm 是铺作外跳。

因此以后任何参数表必须把 `eave_projection` 拆成带起止点定义的字段，不能只写一个“檐出”。

**当前状态：E-032 可作为高等级现状/报告派生几何控制，但仍应在直接看到主报告第147页后完成最终锁定。**

## 3. 架深｜正式论文提供了设计模数候选，但不是现状实测坐标

### E-033｜下架深 = 次间进深的一半｜LATER-HYPOTHESIS / REPORT-DERIVED INPUT

肖旻《镇国寺大殿尺度规律研究》指出：

- 大殿“间椽对位，一间两椽均匀分布”；
- 各架深可按各间进深的一半讨论；
- 下架深（檐柱缝至下平槫）按其足材模数解释为 **5.5足材**。

若暂取 Batch 02 的足材候选 M≈321mm：

- 5.5M ≈ **1765.5mm**。

但这仍属于**设计规律解释**，不是主报告原始三维测点坐标。

因此后续应同时保存：

- `observed_purlin_xy`：主报告实测位置；
- `reconstructed_frame_depth_candidate`：5.5M 等设计候选。

## 5. 转角/山面结构｜获得“主报告横剖面图”的正式再出版证据

### E-035｜2014正式论文直接转载《镇国寺报告》万佛殿横断面图｜A-BRIDGE VISUAL

韩国国立文化遗产研究院期刊 MUNHWAJAE 2014年第47卷第4期论文《韩中木构建筑檩（槫）结合方式变迁比较研究》中：

- 图16明确标注为“镇国寺万佛殿横断面图”；
- 图源明确写为：刘畅等，2013，《山西平遥镇国寺万佛殿与天王殿精细测绘报告》。

论文结合该横剖面图指出：

- 万佛殿纵断面中，托脚并非直接承托槫，而是支撑梁侧；
- 山面歇山附近，托脚也不是直接承槫，而是承托槫下的襻间/相关横向构件；
- 这种做法更接近“稳定内部构架”的斜撑，而不应简单建模为“托脚头直接顶槫”。

### 对3D的直接影响

未来托脚节点不能用简化规则：

`托脚 → 槫`

而应优先按：

`托脚 → 梁侧 / 槫下襻间系统 → 槫`

具体连接点仍需回主报告横剖面图核实。

## 6. 转角结构文献冲突得到进一步解释，但未完全关闭

### E-036｜“隐衬角栿”与“无隐角梁”并不必然互斥｜B/A-BRIDGE CONTEXT

Batch 03 发现：

- 一类资料称镇国寺万佛殿转角设“递角栿、隐衬角栿”；
- 另一类研究把万佛殿列入“只用大角梁、不设隐角梁”的案例。

本批次结合唐宋转角结构研究可进一步明确：

- “隐衬角栿”属于角梁下/角部斜向梁栿系统；
- “隐角梁”是另一项更特定的角梁构件；
- 因此“有隐衬角栿”与“无隐角梁”在术语上可能同时成立，不能直接视为矛盾。

同时，2023年华北唐宋转角结构类型研究把镇国寺万佛殿归入 **Aa型I式 / 递角栿型**，并说明万佛殿彻上露明且转角有上下两道递角栿，属于晚唐—五代高等级殿堂构架特征。

**当前判断：Batch 03 的“文献冲突”应降级为“术语与构件识别待主报告图版校准”，而不是简单二选一。**

## 7. 铺作小斗设计｜主报告第107页的正式学术引用

### E-037｜散斗、齐心斗、交互斗原始设计可能同规格｜REPORT-INFERRED

《建筑史学刊》2023年《基于栱心格线的斗栱构成：中日斗栱尺度设计的比较分析》脚注明确引用《镇国寺报告》第107页，指出：

> 镇国寺万佛殿原始设计中，小斗设计尺寸应只有一种，即散斗、齐心斗和交互斗尺寸相同。

这属于主报告的**设计推论**，不是“现存每个小斗实测尺寸都完全相同”。

未来参数体系可以设置一个：

`small_dou_design_module_candidate`

但需要保留现状构件的离散实测值。
