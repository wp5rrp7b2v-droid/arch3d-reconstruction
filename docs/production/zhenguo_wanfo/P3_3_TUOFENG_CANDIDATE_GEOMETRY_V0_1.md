This step converts the approved Master Spec V0.1 into two visible/buildable geometry candidates without inventing historical metric dimensions.

The geometry is deliberately **normalized / dimensionless**.

It tests:
- whether the two source-supported roles can be represented as stable reusable bodies;
- whether UNKNOWN dimensions can remain explicit while assembly work continues;
- whether future metric envelopes can be replaced without changing component identity.

## 4. Metric policy

No candidate coordinate in this package is a millimetre measurement.

At later assembly:
- width / depth / height will be derived from the local support envelope and neighboring locked components;
- every resulting number remains `RECONSTRUCTED_DESIGN` or `SECONDARY_CALCULATED`;
- it remains replaceable if better evidence appears.
