## 1. 设计目标

在工程实现前锁定三件事：

1. 哪些对象可以进入构件组合体系；
2. 构件之间允许表达哪些基础关系；
3. 这些关系如何通过接口、定位、参数和证据边界被机器表达与验证。

本设计不生成 Blender 几何，不进行整殿重建。

## 2. 组合节点资格

### 2.1 正式构件节点

当前 6 个 P3.1 approved canonical Masters 直接继承现有 `component_id`，不得创建重复身份：

- `CMP-COLUMN-001`｜柱
- `CMP-LUDOU-COLUMN-001`｜柱头栌斗
- `CMP-DOU-SINGLE-LONGKAI-001`｜单向长开斗
- `CMP-DOU-INTERACTIVE-001`｜交互斗
- `CMP-FRAME-LOWER-SIX-CHUANFU-001`｜下六椽栿
- `CMP-FRAME-UPPER-SIX-CHUANFU-001`｜上六椽栿

### 2.2 非正式历史构件节点

- Proxy：允许作为工程辅助/近似/关系测试节点；不得历史化。
- Control：仅工程控制、轴线、位置、尺寸、重复控制用途。
- Envelope：仅边界、包络、空间限制用途。
- Deferred：默认不得作为正式历史构件节点；只有明确工程用途时可引用并保留 Deferred 身份。
- UNKNOWN：允许未知属性存在；不得自动补全或升级证据状态。

原则：**进入组合体系不等于成为历史构件。**

## 3. 构件关系体系 V001

V001 只锁定五类基础关系，不扩张为详细榫卯分类体系。

### R01｜承托关系

- 中文主名：承托
- 含义：A 在结构关系上承托 B。
- 方向：承托者 → 被承托者。
- 至少允许表达：接触位置、支承方向、是否直接承托、证据状态。

### R02｜连接关系

- 中文主名：连接
- 含义：两个构件在结构或构造上存在直接连接关系。
- “存在连接”与“具体榫卯构造已知”必须分离。
- 榫卯形式证据不足时，关系可以成立，但细节保持 UNKNOWN。

### R03｜定位关系

- 中文主名：定位
- 含义：一个构件的位置或方向由另一个构件或控制基准决定。
- 可表达中心对齐、轴线布置、端部/定位面对齐等。
- 定位不等于连接，也不等于承托。

### R04｜重复关系

- 中文主名：重复
- 含义：构件或组合单元按照明确规则重复出现。
- 至少表达：重复对象、数量、方向、间距、起点、参数来源。
- 不允许仅保存最终 Blender copy 结果作为正式重复规则。

### R05｜从属关系

- 中文主名：从属
- 含义：某构件属于某个更高层级组合单元。
- 表达组织层级，不代表连接、接触或承托。

## 4. 关系语义边界

正式锁定：

- 承托 ≠ 连接；
- 连接 ≠ 榫卯已知；
- 定位 ≠ 连接；
- 从属 ≠ 接触；
- 重复 ≠ Blender Copy；
- 视觉接触 ≠ 已确认结构关系。

## 5. 组合接口模型

每个参与正式组合的构件可定义一个或多个组合接口。V001 接口至少包含：

1. 接口身份；
2. 接口类型：点 / 轴 / 面；
3. 相对构件局部坐标的位置；
4. 主方向；
5. 允许参与的关系类型。

不得把 Blender 世界坐标作为唯一正式依据。

具体工程实现可使用 anchor / datum / local origin / semantic interface 等技术，但人工可读文档以中文“组合接口 / 定位基准”等概念为主。

## 6. 正式关系记录最小信息

每条关系至少具备：

- 唯一关系 ID；
- 关系类型；
- 起始节点；
- 目标节点；
- 起始接口（按关系需要）；
- 目标接口（按关系需要）；
- 方向性；
- evidence status；
- provenance；
- replaceability；
- 参数引用；
- 备注（备注仅解释，不替代机器规则）。

## 7. 尺寸来源规则

构件 Master 参考尺寸与建筑中的实际组合尺寸必须分层：

`构件身份 → 组合关系 → 建筑层级参数 → 实际实现尺寸`

禁止：

`Master 当前参考尺寸 → 直接复制为建筑实际尺寸`

特别是六椽栿 `canonical_reference_length_mm=1000` 只能表示 canonical Master 的 NON-HISTORICAL / REPLACEABLE reference specimen，不得作为万佛殿实际六椽栿长度。

## 8. 关系证据状态

关系本身必须独立记录 evidence status。构件证据状态与关系证据状态不得互相自动推导。

允许例如：

- 柱承托柱头栌斗：CONFIRMED；
- 柱与栌斗的具体连接构造：UNKNOWN。

组合成立不得自动提高历史确定性。

## 9. 组合单元定义

组合单元 = 一组具有明确构件身份、关系和参数边界，并可作为更高层级组合对象复用的构件集合。

正式组合单元必须具有：

- 唯一身份；
- 成员节点；
- 内部关系；
- 外部接口；
- 参数输入；
- evidence boundary。

Blender Collection、任意选择集或视觉上完整的一组模型，不自动构成正式组合单元。

## 10. P3.2 首批代表性关系覆盖

后续工程阶段至少验证三种模式：

1. 竖向承托链：柱 → 柱头栌斗 → 上部构件；验证承托 + 定位。
2. 横向梁架链：斗 / 柱头体系 → 六椽栿体系；验证连接 + 定位 + 尺寸传递；未知连接细节保持 UNKNOWN。
3. 重复关系：起点 + 数量 + 间距 + 方向驱动重复布置；证明不是手工复制。

T-015 本身只建立支持这些关系的基础数据结构和 Validator，不要求完成上述全部组合实例。

## 11. 后续机器验证最低覆盖

Validator 至少能够检查：

- 节点不存在；
- 重复节点身份；
- 非法自连接；
- 非法关系端点；
- 孤立正式节点；
- 必要关系缺失；
- 非预期循环；
- 从属层级循环；
- 父子关系冲突；
- 关系引用不存在接口；
- evidence 字段缺失；
- UNKNOWN 非法升级；
- Proxy / Control / Envelope / Deferred 静默历史化；
- reference length 泄漏到建筑实际尺寸。
