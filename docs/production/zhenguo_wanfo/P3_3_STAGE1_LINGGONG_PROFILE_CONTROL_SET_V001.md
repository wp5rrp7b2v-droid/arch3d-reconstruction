## 6. Independent shape rationale

Candidate 01 preserves only broad features visible in the same-building source context:

- continuous horizontal upper bearing line;
- short terminal end drops;
- relatively open outer underside transition;
- two broad descending zones rather than many decorative micro-breaks;
- a short broad central low zone instead of a needle point;
- bilateral symmetry for the canonical Stage1 family body;
- no carved micro-profile, socket, groove, mortise, tenon, slot or cavity.

The point layout is intentionally simpler than T-037 and T-038 and was not generated by scaling, averaging or morphing either prior control set.

This remains a reconstruction control polygon, not measured historical curve geometry.

Product Owner review should check:

1. upper line reads as stable horizontal bearing surface;
2. end drops are short and not decorative;
3. lower edge descends in broad, simple stages;

6. no feature suggests invented joinery;
7. the 令栱 profile is visibly independent from the locked瓜子栱/慢栱 control polygons;
