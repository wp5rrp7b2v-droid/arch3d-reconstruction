日期：2026-11-07。工作单元：验证无需 Product Owner 截图，能否自动取得网站《柱头铺作》的可追溯视觉画面。**不进行模型修正，也不授权把网站展示图当做实测图。**

## G0 最小验证与判定（预先定义）

1. 使用 GitHub Actions Linux + Playwright/Chromium 打开**一次公开网页**。不绕过验证码或授权，不需要 PO 手工截图。
2. 验证 HTTP 状态和页面可见文字；自动定位“柱头铺作”（或“铺作”）节点，滚动至该处后截图；另尝试“卷杀/栱端方直”截图。
3. 读取加载图片的原始网址（剔除参数）、尺寸、距标题距离；若网站通过 canvas/其他技术展示，也只报告存在，不自动把它视作可提取3D模型。
4. 保存截图的 SHA-256、文件大小、页面结果；**不把整张网站截图或图片素材提交到公开 GitHub git 历史**。截图仅保留于本轮短期 Actions Artifact，元数据留在本审核分支。

PASS_AUTO_CAPTURE_SECTION：网页可访问，自动捕获“柱头铺作”目标文字及其附近至少一张实际加载图片。**这只能说明自动捕图能力 PASS，仍不能证明该图是东缝前柱头的真实第一跳华栱。**

PARTIAL_TEXT_ONLY：仅能读到相关文字，尚不能定位足够清楚的站内近景。

FAIL_AUTOMATED_BROWSER_REFERENCE：站点无法被本轮云端浏览器验证访问，或不能可靠定位指定文本。

更高门槛的工程使用要求：构件照片可识别、同部位比对可核对来源、A1/A2 原始资料支持；通过G0不自动开始建模。
