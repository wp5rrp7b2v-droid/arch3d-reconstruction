## G4 最小试验和事先验收门槛

1. **来源门**：只从已验证的指定官方公开模型URL读取 `dougong.gltf/bin`，必须与G1/G3记录的两个SHA-256逐字节一致；第三方源文件不进入 Git。
2. **几何门**：在真实导入的原网格上，逐对检查4件之间的6组面片-BVH交集及双向顶点到三角表面的最短采样距离；写出模型源单位的可重复数值。各网格独立记录闭合/非流形边情况。
3. **剖面门**：至少2个使用 Blender BMesh 实际三角网格 `bisect_plane` 得到的剖面渲染，加2个未切的原位视角。两切面共享同一场景，不能用包围盒图冒充剖面；审图留SHA。
4. **解释门**：
   - 有BVH三角面相交可证明“来源模型的三角面相交/共面”，**不能直接证明材料体积穿透或承重连接**。
   - 没有面相交且顶点-面采样非零，只能说明“在本方法中未检测到三角面相交”，不能排除完全包含等情况。
   - 有包络交叠不能算模型网格有真实接触。
5. **建筑证据门**：由A1 PDF73（印刷58页）图2-27和项目其它已归档材料，判断这些几何结构是否支持实际万佛殿同一柱头栌斗/第一跳华栱。没有对应对象ID、同位证据、实测尺度时，保留UNKNOWN。

**PASS**：输入SHA匹配、6组实际三角面测试、4个非空视图和2个真实几何剖面能够重跑，并能明示面交集与未证明项。

**FAIL**：任何必需数据错误/未实际执行或关键网格未找到；禁止把“没有相交”默认为“没有装配关系”。

即使技术 PASS，若缺乏A1/位置对应证据，实际历史构件身份和可供正式生产的榫卯仍为 FAIL/UNKNOWN，不能启动第二版正式建模。
