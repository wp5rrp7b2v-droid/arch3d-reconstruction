候选保留既有明确的**数值与参考控制关系**。主候选不擅自重排正式Master坐标；华栱和令栱Master中“栱广”被放在侧向挤出轴，而部分工作实例把约153毫米厚置于侧向、约220毫米置于竖向。这是已读到的**坐标与截面表达差异**，不是可静默消除的几何细节。此处不撤销尺寸批准，也不声称已裁定所有型号的正确轴映射。图片标的是“长×侧宽×图示高”，不是把所有竖向包络都称作材广。

头昂、二昂左侧试装图显示装配后的投影包络，并另列按既有24.075498255°设计斜度回转后的轴向尺寸。局部昂的材广分别约278.4000与187.0000毫米，与Master参数吻合，但长度、端头、局部切口与完整网格并不相同。不能把“不是同一网格”误说成全部尺寸都错。

**候选只供形制方向审核，不是可直接装配的替换件。** 正式Master和试装件的完整模型身份均被保留；尚未验证候选与当前89件的接触／碰撞。保留包络不等于保证接口相容。

## 图像、推断和未知怎么区分

- **FACT｜直接证据**：归档模型顶点、面、包络、轴向数据；PDF73图2-27照片可见斜昂和卷杀；PDF87图2-46最外跳横栱的可见端部；PDF60令栱位置原文。
- **INFERENCE｜推断**：完整候选曲线、对称化、集中卷杀的起点、深头过渡与外端收削比例。图2-27下半幅是报告的交接关系解释图，不能升级为独立实测单件真值。
- **UNKNOWN｜尚未确定**：隐藏后尾、整材历史全长、精确榫卯与上口、被遮挡接缝、个体对应、修补年代与实例差异。未在候选中增加仿宋／明清装饰、猜造榫卯或损伤。

候选数值是可修改的建模控制，不是从照片获得的测量点。本轮没有做照片比例标定，也没有以他寺完整外形冒充万佛殿原形。有限同殿证据足以提出可审的基本形制方向，尚不足以证明唯一历史外形；PO可以接受或要求局部修正。

`sources/`保存实际使用的完整原始页、既有官方提取参考及正式Master语义网格文件。报告照片未重绘；对照图只是裁切、等比重采样、中文箭头与框选。原页字节SHA256已与PR72来源表交叉核对。官方提取件是既有展示材料、身份仍属推断，本轮没有把其三维形状当实测真值。

- `TRACEABILITY.json`：输入提交、模型路径、来源PDF及逐文件哈希、渲染方法。
- `sources/PR72_PAGE_PROVENANCE.json`：PR72实际来源条目。
- `sources/PR74_TARGET_SUMMARY.json`：PR74的F028／029／030／035／036，剔除冗长实例清单，其余保留。
- `MODEL_EXTRACTION.json`：8个目标局部试装网格的真实身份、包络、朝向、世界坐标范围与面数。
- `MODEL_COMPARISON.json`：逐个Master／局部试装件的实际差异；按尺寸归一的轮廓交并比仅辅助区分形状，不充当历史正确性分数。昂先回转斜度再比较；控制段与全工作长度仍不能视作同一长度范围。
- `geometry/*_master.json`：原Master顶点准确保留的三角化只读提取。
- `geometry/*_trial.json`：来自GLB真实网格、经过记录的刚体观察变换，非重新创造。
- `geometry/*_candidate.json/.glb`：独立待审候选；主候选五体和两个昂的完整工作长度候选均单独命名；JSON毫米，标准GLB米。
- `CONTACT_LOCATIONS.json`：原89件14组相关接触的世界坐标多边形、包络与面积。8组西缝面积与PR75记录吻合。此文件不表示候选接口通过。

本轮证明：

4. 原89件、Master、Registry、工程状态与历史资料未改；原工程验证和视觉不通过结论不被覆盖。

尚未证明：963年唯一完整外形、所有个体精确尺寸、候选接触／碰撞、真实榫卯与承载力。`PASS`仅限注明的提取、文件、尺寸保持与交付检查；**形制最终验收仍由PO进行**。

## 复现

本轮直接读取原始几何与GLB，使用Python CPU光栅化，没有下载或执行本地Blender。后续如需Blender工程执行，继续使用GitHub Actions云端。
