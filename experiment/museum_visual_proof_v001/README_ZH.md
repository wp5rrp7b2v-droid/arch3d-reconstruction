# 万佛殿｜以数字博物馆为视觉参考的独立造型试件 V001

**2026-11-07 / Draft PR #86 / 仅独立试件 / 不修改正式基线**

## PO此次明确的方向变化
此前：项目自己构件的分层装配和接口优先；PR83只通过单接口几何验证，博物馆为待研究参考。

本次 PO 指示：“还是按照数字博物馆来建模吧”，批准将数字博物馆斗栱组合的可见层次与整体组织方式放到**新候选试件**的视觉参考首位。A1/A2 的实测证据与已批准 Master/Registry 仍有效，本次不撤销或覆盖，待最小端到端试验通过及 PO 审核再决定正式生产基线变化。

## 已经做出的技术选择
- 不直接下载并复制第三方 glTF 顶点、贴图或单构件模型：该网站官方复用授权尚未证明，且 G1 证据已证实其 `dougong.gltf` 96个网格都是 `polySurface...` 泛化标签，具体栌斗/华栱身份无法查证。
- 新试件是从零编写原创 Blender 参数化代码，仅借鉴博物馆的多层横向出跳、两方向交错栱、层间小斗、可见斜昂的总体视觉语法。
- A1 图2-27（精细测绘报告PDF73/印58）用于核对栱昂与斗的总体层级；该图并不提供本试件各个独立构件的全部几何尺寸或榫卯。
- 在精确尺寸证据不足时，暂以相对单位制作**可否呈现组合视觉**的廉价实验。所有脚本长度/间距均是工作假设，不能当历史测量值。

## 验收与结果界限
1. G0 模型构建：云端 Blender 实际生成 BLEND+GLB，有独立部件和三张可见视图，源代码可复运行。
2. G1 造型：PO实看试件，对比数字博物馆三视图，判断是否更接近其层次和外观；未经 PO 通过，不可变更视觉基线。
3. G2 结构与测绘：把通过G1的对象按A1/A2可核数据重新定尺，以原正式 Master 和相应连接输入复核实接触、穿插、榫卯、两视图外形并重新输出验证结果。G2未执行。
4. G3 Canonical：G1+G2完成且PO明确批准后才考虑并入正式模型。本次绝不触及main、Registry、Master或PR83。

## 已知道的失败风险
- 数字博物馆的视觉展示不代表工程精度；具体位置映射尚未知。
- 仅从视觉图生成有可能出现“看起来连着但几何悬空”。
- 本轮没有接触面积、布尔穿透、受力承载、榫卯、真实绝对尺寸验证；**绝不能宣称装配PASS**。
- PR81以前的外形失败并不证明其所有工程约束应作废；PR83技术PASS继续成立。

## 验收结论原则
本轮最多得出 **“数字博物馆视觉启发的原创层次组织可渲染”**；不能得出“万佛殿历史真实斗栱已建成”。若G1视觉失败，应保留技术试验记录，调整定位、目标源或重新进行参考选择，而不能扩大生产。
