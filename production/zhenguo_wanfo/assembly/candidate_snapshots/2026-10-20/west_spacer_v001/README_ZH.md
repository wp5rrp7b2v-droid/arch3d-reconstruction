# 万佛殿｜西缝上六椽栿与前后隔架试装 V001

## 本工作单元

将已在东缝工作模型中建立的 **上六椽栿候选及前后隔架七件**，按西缝四椽栿的现有位置关系作一次受控试装，形成 82 + 7 = 89 实体联合 **工作候选**。这是几何装配实验，不是对963年历史形制的认证。

### 正式基底与资料成果

- 原始82实体文件：2026-10-13上六椽栿前端 C01 云端核验工作BLEND；SHA-256 `baf43fc29fd9a769c89a0edc5cd4137d107133bf20239677105dde9baaa06e54`，从本分支继承的已公开归档文件读取。
- 此基底包含东缝前端C01及斗形C02已批准的**局部设计**，也包含若干未批准候选；**原82件完全保持，不扩张批准**。
- PR #72/#73/#74 研究与形制图片保留原Draft/分支、供外形参考；停止进一步追查造型来源，不以未证实图像产生新构件实体。
- 本单元仅延展既有建模成果，不修改Master、Registry、505实体登记、Dashboard、Project Control或main。

### 西缝工作假设

- 东缝7件的**局部形制只作为待检的复制候选**，不预设东西两缝历史完全相同。
- 放置基准：现有东西四椽栿包络中心的 X/Y 差、底面Z差；预期平移量 `(-4437, 0, -27) mm`，需以实际打开的两根梁作断言。
- 原件：东缝上六椽栿候选1件、前端华栱/令栱/散斗3件、后端两件令栱/散斗3件。西侧新增7件并全部标记`PENDING_WEST_SPACER_V001_REVIEW`。
- 复制不改变任何已批准原件。东缝模型中已有未批准的前端柱头候选及下六椽栿端段不会随此次复制扩张到西侧。

### 最小端到端验证

1. 以基底BLEND的SHA256严格校验输入身份。
2. GitHub Actions云端 Blender 4.5.13 生成、保存、**另一次Blender进程**重开89件BLEND；不使用用户本地Mac。
3. 核实原82件局部网格、三角面及变换完全一致；新7件网格与东缝来源相同并只发生测得的平移，世界坐标误差小于0.001毫米。
4. 新增件为封闭、正体积单连通；89件合计3916对穿插核查，任意一对超过1立方毫米则FAIL。
5. 东侧8条对应内部承托接触在西侧均保持大于100平方毫米且相对偏差不超过0.01%；前后散斗与西缝四椽栿接触均大于100平方毫米。
6. 生成西缝局部和东西两榀整体两张实际渲染图，供PO审阅；视觉形制审核与技术检查分别评价。

**PASS只证明有限范围的几何相容和文件可重开。** 此工作单元不验证真实历史尺寸、榫卯、力学、最终外观，也不允许将试装件自动写入正式Master。任何一项FAIL都不得把候选晋升或合并main，先据真实验证结果修正。
